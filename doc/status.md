# 已知问题

## 未验证的能力

- 多机 mesh 的真实三机部署已实测：mac/home4/kuma 三条关系、六个方向都取得 direct_reachable、currently_healthy 与透明承载证据（ICMP 20/20、TCP 64 KiB 与 UDP 512 B 双端 SHA256 一致），单 actor 多 topic 限流在真实三机上未随关系数放大。仍未取得证据的是公网 P0 资格、长期稳定性与故障恢复，见下。

- 公网完全不可用时的真实双机 LAN 独立冷启动尚未实测；当前有对应离线回归测试。
- 真实休眠/唤醒、系统重启、物理换网后的自动恢复，以及长期稳定性均未验证通过。服务进程重启不等于系统重启。
- 公网 P0 门槛未达成：每端至少 5 次记录更新、传播 p95 ≤120 秒、3 次独立公网冷启动各 ≤180 秒尚未验证通过。

## 网络拓扑限制

- 公网候选在两端同一公网出口之后（同一公网 IP、不同端口）仍可能受 NAT 回环或中间过滤限制，根因未确认。LAN 自动发现只适用于可见 Bonjour、具有实际 RFC1918 直连路由的同网段，不提供跨 VLAN 或过滤环境中继。

## 数据面与性能

- RTT 抖动明显，单连接 TCP 吞吐存在方向差异；未测物理线路基线和隧道进程 CPU，不能区分是线路还是实现造成。
- 曾观察到 `invalid_local_ipv4` drop 计数增长，原因未定位。
